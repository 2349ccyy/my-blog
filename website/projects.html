电商售后评论分析与退款风险预测

2026.02 — 2026.06
BERT MacBERT PyTorch Transformers Python

项目描述

面向电商售后场景，构建方面级情感分析与退款风险预测模型。售后评论通常同时包含商品质量、物流履约、客服服务、退换货体验、价格争议和退款倾向等多个风险维度，因此不采用整句二分类，而是将每条评论与不同风险方面组合为"评论 + 风险方面"的句对输入，让模型识别每个方面上的情感倾向，再聚合为退款风险分数、风险等级和可解释的证据评论。

项目职责

  • 数据建模：设计方面级建模方案，将售后评论拆解为商品质量、物流履约、客服服务、退换货体验、价格体验、退款倾向等 7 个风险方面，每条评论与多方面组合生成训练样本；按评论编号划分数据集，避免同一评论的不同方面泄漏到训练/测试集
  • 数据处理：完成字段校验与标签统一（正面/中性/负面/未提及），过滤空评论与异常标签，将原始评论数据转换为"评论文本 + 风险方面 → 标签"的长表训练格式，保证样本可追踪
  • 模型训练：采用句对输入方式，基于 bert-base-chinese 完成基线验证，确认任务可行性；再使用 hfl/chinese-macbert-base 作为落地模型，MacBERT 对售后评论中的口语化表达和隐含情绪理解更优
  • 类别不平衡处理：针对未提及样本占比过高、高风险样本过少的问题，根据标签分布引入 class weight，训练时加大对负面和高风险样本的惩罚权重；评测时以 Macro-F1 和高风险 Recall 为核心指标，而非仅看整体准确率
  • 风险聚合与可解释性：推理完成后按风险方面聚合预测结果，设计 risk_score = negative_rate × 0.8 + neutral_rate × 0.2 的风险评分规则，映射为低/中/高/紧急四级风险等级；对高风险方面自动提取置信度高、含明确风险关键词的评论作为证据
  • 结果输出：生成预测结果表、风险分数表、风险等级表、证据评论和风险分析报告，将文本分类结果转化为业务可读的退款风险结论

项目成果

完成从数据处理、模型训练、评测到风险报告生成的端到端流程；模型不仅能判断评论是否有退款风险，还能解释风险来源（商品质量/客服/物流/退款倾向等），并通过证据评论提供可追溯的判断依据。模型效果以 Macro-F1 和高风险 Recall 为核心指标，后续可扩展为售后风险监控或客服辅助决策系统。

AI面试模拟与简历诊断助手

2025.08 — 2025.12
Coze 工作流 知识库 Fun-ASR Python Coze API

项目描述

设计并搭建基于 Coze 的智能面试助手，实现简历评估、录音分析、面试题生成三大核心功能。

项目职责

  • 简历分析：构建 7 节点工作流，从简历中抽取姓名、技能、项目等 7 类信息，结合违禁词表与规则引擎自动生成修改建议，诊断效率提升约 60%
  • 录音分析：集成 Fun-ASR 转写语音，通过角色分配与问答对提取，循环检索知识库进行答案分级（A~D），自动输出弱项总结与正确答案
  • 面试题生成：将简历技能点拆分为 20+ 关键词，循环检索面试题库与知识库，为每人动态生成 25 题（含技术、项目深挖、人事问题），重复率低于 5%

项目成果

在 30 份真实简历与 20 段模拟面试中测试，简历建议采纳率 75%，弱项识别准确率约 82%；项目获校内模拟面试活动采用，服务 200+ 同学。
