电商多智能体中台 | RAG Agent 和商品上架 Agent

2025.06 — 2026.06
LangGraph LangChain Milvus BGE-M3 BGE-Reranker MiniLM FastAPI PostgreSQL Redis Pydantic SSE LLM

项目描述

面向电商企业的商品运营与客服协作场景，构建基于 LangGraph 的多智能体运营中台，覆盖企业知识问答、商品上架审核、经营数据分析、售前转化和售后履约等业务能力。我主要参与企业知识 RAG Agent 与商品上架审核 Agent 的设计和开发：前者基于原有的传统 RAG 升级为多Agent 智能体，为全员提供基于企业私有资料的可追溯问答能力，重点辅助客服生成经人工确认后可发送的答复草稿；后者对商品标题、属性、图片进行多维规则审核，输出风险分级、字段级改写建议和人工审批任务，降低人工上架返工与违规风险。

项目职责

  • 智能问题路由：使用 LangGraph 编排，设计规则、MiniLM 和 LLM 三级问题分类，实现企业知识 RAG Agent 的离线建库与在线检索链路，支持 PDF、Word、Markdown、Excel 等企业资料解析
  • 混合检索 + 精排：基于 BGE-M3 生成 Dense 稠密向量和 Sparse 稀疏关键词向量，写入 Milvus Collection；在线查询时通过 Milvus Hybrid Search 分别执行语义召回和关键词召回，使用 WeightedRanker 融合结果，并结合 BGE-Reranker CrossEncoder 精排，提升检索准确率
  • 商品上架审核 Agent：使用规则引擎完成必填属性、标题长度、禁限售词、资质有效期、类目依赖、图片尺寸和 OCR 文本等确定性检查；结合 LLM 识别夸大宣传、语义矛盾和类目适配风险，并生成字段级 JSON Patch 改写建议
  • 审核状态机与人工闭环：设计商品审核状态机和人工审核闭环——商品素材经标准化、规则匹配、硬规则检查、图片检查、语义审查、风险聚合和报告生成后进入人工审核；高风险商品强制阻断发布，发布前再次校验商品版本、规则版本、审批有效期

项目成果

RAG 侧：离线评测集 Recall@5 ≥ 90%、引用正确率 ≥ 95%、高风险问题拦截率 100%、无依据问题拒答正确率 ≥ 95%，P95 响应时延 ≤ 8 秒。

商品审核侧：硬规则召回率 ≥ 95%、高风险误放行数为 0、审核报告 P95 生成时延 ≤ 3 分钟、审核记录可追溯率和发布幂等率均达 100%，商品从素材齐备到人工审核结束的平均周期较原人工流程缩短 40% 以上。

电商企业私有知识库传统 RAG 系统

2025.06 — 2025.12
LangChain Milvus BGE-M3 BGE-Reranker BM25 MySQL Redis FastAPI LLM

项目描述

构建电商企业私有知识库问答系统，覆盖售后政策、物流发货、商品参数、平台规则、优惠活动及客服 SOP 等高频知识。系统采用"FAQ 快速匹配 + RAG 检索增强生成"双路架构：对标准高频问题直接返回统一答案，对复杂或长尾问题从企业知识库中检索依据并生成带引用的答复建议。

项目职责

  • 离线建库链路：支持 PDF、Word、Markdown、TXT 等文档解析，采用父子分块策略；补充店铺、品类、文档版本、生效时间、发布状态等元数据，实现知识版本可追溯与过期文档隔离
  • 混合检索 + 精排：基于 BGE-M3 为知识块生成稠密向量和稀疏向量，写入 Milvus Collection；在线检索时执行 Dense 语义召回与 Sparse 关键词召回，并通过 BGE-Reranker 精排提升检索效果
  • 双路问答流程：使用 BM25 在 MySQL FAQ 库中进行高频标准问题匹配，高置信度时直接返回标准答案；未命中时进入 Milvus 检索链路，将 Top-K 高相关知识块、用户问题及会话历史组装为 Prompt，调用 LLM 生成带引用、适用条件和追问建议的答复

项目成果

完成电商企业私有知识库传统 RAG 系统的建设：通过 FAQ 快速命中降低高频问题的大模型调用成本，通过"混合检索 + 重排 + 引用约束"提升复杂问题的可追溯性，提升客服查询商品规则、物流政策和售后 SOP 时的资料定位效率。

基于 Dify 工作流智能面试助手

2024.06 — 2024.09
Dify Dify Workflow Fun-ASR RAGflow Python 提示词工程 LLM

项目描述

面向求职者模拟面试与简历优化场景，构建基于 Dify 工作流的智能面试助手。系统对用户上传的简历和模拟面试录音进行结构化分析，识别技能匹配度、项目表达完整性、违禁表述、知识薄弱项及回答逻辑等问题，并输出简历修改建议、能力评估等级、薄弱点总结和个性化面试题，为求职辅导、模拟面试和面试复盘提供支持。

项目职责

  • 简历评估工作流：基于 Dify 搭建，编排文件解析、LLM 信息抽取、代码处理、条件分支、知识库检索和结果输出等节点；从简历中提取个人信息、技能栈、项目经历、教育背景等 7 类关键信息
  • 简历优化逻辑：结合违禁词库、岗位要求及规则引擎，对简历中的表述规范性、技能匹配度和项目描述完整性进行评估，自动生成可执行的修改建议
  • 面试录音分析：集成 Fun-ASR 实现模拟面试录音转写，通过 Dify 工作流完成问答片段提取、候选人回答分析及知识库检索；从准确性、完整性和表达逻辑等维度对回答进行 A~D 分级，定位候选人的薄弱知识点
  • 个性化题目生成：基于简历技能和项目经历拆解 20+ 个关键词，结合 Dify 知识库、循环节点与 LLM 动态生成技术原理、项目深挖和人事沟通类面试题；通过代码节点进行相似题过滤，输出个性化题库与参考答案

项目成果

完成从简历解析、简历优化、语音转写、面试回答评估、知识库检索到个性化题目生成的全流程开发；在 30 份简历与 20 段模拟面试录音中进行测试，简历建议采纳率达 75%，薄弱项识别准确率约 82%。
